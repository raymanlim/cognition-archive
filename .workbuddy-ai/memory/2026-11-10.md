## 构建「世纪文库·极简典藏风」思想认知网站（Astro 5）
- 需求来源：`design.md`（开发规格）+ `C:\Users\shand\Downloads\gemini-code-1794244300142.md`（Gemini 内容规格）。
- 技术栈：Astro 5 + Tailwind CSS v3 (`@astrojs/tailwind`) + TypeScript，静态输出，部署目标 Cloudflare Pages `raymanlim.us.ci`。
- **核心架构决策**：素材 md 留在项目根作为唯一数据源，`scripts/parse-sources.mjs`（纯 Node 正则、零依赖）在 `predev`/`prebuild` 自动解析 5 份 md → `src/data/generated/*.json`；TS 数据层负责强类型、作者分组、英文对照与派生字段。素材改了自动同步，不会漏卡。
- 数据规模（已校验）：思想认知 23 卡、现实透镜 25 卡、芒格 6 学科卡 / 52 模型、CPV 14 章、27 位哲学家、8 条串联公理。
- 交互实现：`src/scripts/site.ts` 单个客户端 bundle，用 `data-*` 属性 + 事件委托实现三态语言(zh/en/bi)、三态主题(paper/dark/crisp)、Tab、双维过滤、折叠、检查表；不引入 React island。主题/语言用 CSS 变量 + `html[data-theme|data-lang]`，防闪烁脚本内联在 head；localStorage `rayman_theme` / `rayman_lang` / `rayman_checklist`。
- **零外部字体**：只用系统衬线栈，避免 `fonts.gstatic.com` 不通导致构建期卡住（沿用既有排查结论）。
- 算法：`src/utils/cognitiveEngine.ts` 中 `buildCrossLibraryMatrix(cardId)` = 25 张卡的策展映射 + 8 公理关键词加权自动补全，输出哲学底座 / CPV 诊断 / 认知卡 / 芒格模型四层联动，眉批可跳转锚点。
